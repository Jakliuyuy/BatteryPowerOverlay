# BatteryPowerOverlay — 电池功率悬浮窗 (Material 3 原生重构版)

Android 实时电池动力监视工具，支持**全功能桌面悬浮窗**与 **LSPosed 状态栏原生同级内嵌 Hook** 双模式，专为 root/玩机极客打造。

---

## ✨ 核心特性

### 1. 现代化架构规划：主菜单 + 次级页面分层设计 (v3.2.0)
- **告别臃肿单页长列表**：彻底重构原有平铺冗长的单一视图，采用现代化“首页核心仪表盘 + 模块化主菜单入口 + 专属次级精细配置页面”的原生结构；
- **首页核心动力看板**：超大字号实时功率指示（充电翡翠绿、放电琥珀金）、四宫格高频动力指标（电流、电压、电量、温度）以及微缩所见即所得双模拟视窗；
- **结构化四大主菜单卡片**：
  1. 📱 **桌面悬浮窗管理**：外观胶囊质感、字号、颜色、吸附、位置锁定与快速开关；
  2. ⏱️ **状态栏 Hook 定制**：图层模式二选一（独立覆盖图层 / 并排流式图层）、时钟左右锚点、Translation X/Y 硬件级位移微调与预设、1:1 克隆时钟字体与颜色自适应；
  3. ⚡ **全局与刷新频率**：统一集中调控采样节拍，悬浮窗与状态栏双向同步；
  4. 🛠️ **硬件适配与诊断**：双电芯倍率修正、极性翻转校准、内置驱动节点探测终端与一键报告复制。

### 2. 全局统一刷新频率体系
- **悬浮窗与状态栏完全同步**：统一收拢原本分散的采样节奏，全局提供 5 档精选档位：
  - `500 ms`：⚡ 极速灵敏（2次/秒，快充瞬时功率捕捉）
  - `1000 ms`：⚖️ 标准均衡（1次/秒，默认推荐，流畅度与能耗完美兼顾）
  - `1500 ms`：🌱 温和节能（约0.67次/秒，轻微降低唤醒）
  - `2000 ms`：🔋 超长续航（0.5次/秒，适合日常待机与省电）
  - `3000 ms`：🌙 极致省电（约0.33次/秒，近乎零能耗消耗）
- **毫秒级跨进程热推**：基于 `ContentObserver` 与同步 `commit()`，修改即时推送到 SystemUI 进程与悬浮窗后台服务，无需重启手机。

### 3. 状态栏 Hook 原生同级内嵌 (彻底根治开机漂移与丢失)
- **时钟原生兄弟节点（Sibling View）排版**：
  - 彻底淘汰脆弱的“顶层 FrameLayout 算绝对 leftMargin 追踪时钟”的旧设计；
  - 直接将功率 TextView 作为状态栏 Clock 的原生兄弟节点注入到时钟父容器中；
  - **几何级天然防漂移**：时钟在开机冷启动、DisplayCutout (刘海/挖孔) 避让、通知图标增减、屏幕旋转时，功率视图与时钟完全共享相同的流式排版上下文，永远如影随形，漂移率直接归零！
- **图层模式二选一**：支持【独立覆盖图层（悬浮于通知上方，完全不占通知图标空间，推荐）】与【并排流式图层（与时钟流式并列）】；
- **硬件加速位移微调**：采用 Translation X / Y 进行像素级微调（-300px ~ +1300px），支持一键定位至屏幕最右端，不干预父容器 Measure/Layout，杜绝循环布局闪烁；
- **颜色与字号自适应**：自动提取时钟文本色与字体特征，1:1 克隆 ColorOS 17 系统时钟；
- **Direct Boot 跨重启持久化**：采用设备保护存储与 SystemUI 磁盘本地缓存，手机重启未解锁阶段即刻恢复样式。

### 4. 桌面全功能悬浮窗
- **5 款质感胶囊外观切换**：
  - 雾面毛玻璃（柔和磨砂，微光边框）
  - 雅致深灰胶囊（经典深灰，质感细腻）
  - 纯净雪白胶囊（清雅雪白，浅色壁纸绝配）
  - 极简微光描边（科技极客风）
  - 极简全透明（无边框，极简沉浸）
- **屏幕防越界与自由拖动**：手势随意拖动，拖动松手即刻通过 `commit()` 同步落盘，永久记忆坐标；
- **支持一键居中复位与位置锁定**，防止日常误触移位；
- **支持边缘智能吸附**；
- 字体大小、文字颜色（调色盘弹窗）、显示项全面可控。

### 5. 高级硬件适配与内核直读
- **键值标签化解析**：彻底杜绝个别内核节点缺失时的字段错位；
- **智能电流单位判定**：自动识别 μA 与 mA，彻底兼容一加 Ace 6T 及各类高通/通用机型；
- **双电芯闪充支持**：针对串联双电芯机型提供功率翻倍自适应开关；
- **充放电极性校准**：针对特殊定制内核提供正负号翻转开关；
- **内置底层诊断终端**：一键探测当前机型 `/sys/class/power_supply/` 节点路径并支持复制。

## 🚀 安装与使用

1. 安装生成的 APK，根据引导授予**悬浮窗权限**；
2. 打开悬浮窗开关，在弹出的 Root 权限弹窗（KernelSU / APatch / Magisk）中允许授权；
3. 如需使用状态栏内嵌模式：
   - 在 LSPosed 管理器中启用本模块，作用域勾选 **SystemUI (系统界面)**；
   - 点击 App 主界面的【重启 SystemUI】加载模块；
   - 之后在 App 内任意修改位置、颜色、字号均实时热生效！
